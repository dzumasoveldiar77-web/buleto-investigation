# BULETO INVESTIGATION 1.0 — стартовый каркас

Независимая исследовательская панель для аккуратного хранения и анализа проверяемых результатов. Это первый локальный MVP, не подключённый к Buleto и не содержащий вымышленных данных.

## Что уже работает
- Импорт CSV с колонками `timestamp,number,source`.
- Проверка даты и целого числа в диапазоне 0–36.
- Отсечение повторов по паре timestamp + number.
- Частоты всех 37 чисел и список последних 20 записей.
- Экспорт импортированного набора в CSV.
- Локальное сохранение в браузере устройства.

## Ограничения текущей версии
- Данные хранятся только в браузере/устройстве; очистка данных браузера может их удалить.
- Нет автоматического сбора с Buleto, API, WebSocket или серверной базы.
- Импортированный CSV сам по себе не подтверждает подлинность источника. Для публикации нужны происхождение файла, время получения, контрольные суммы и независимая проверка.
- Частоты не предсказывают следующие результаты. Небольшая выборка не позволяет делать вывод о честности или нечестности платформы.

## Запуск
Откройте `index.html` в браузере. Для локального веб-сервера можно использовать любой статический сервер. Проект не требует npm-пакетов.

## Формат CSV
```csv
timestamp,number,source
2026-11-01T00:00:00+06:00,17,official-export
2026-11-01T00:01:00+06:00,4,official-export
```

## Принципы исследования
- Не обходить авторизацию и не получать закрытые данные без разрешения.
- Не делать ставки для экспериментов.
- Не называть статистическое отклонение доказательством манипуляции.
- Хранить исходные данные неизменными и отдельно хранить результаты анализа.
